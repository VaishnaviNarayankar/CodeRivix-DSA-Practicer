# CodeRivix – DSA Practicer

A web-based platform designed to help learners practice Data Structures and Algorithms (DSA), strengthen problem-solving skills, and prepare for technical interviews through organized topics, difficulty-based problems, and progress tracking.

## ✨ Features

### 📚 Structured DSA Learning

* Explore DSA concepts organized by topic.
* Practice problems across multiple difficulty levels.
* Strengthen your understanding of fundamental data structures and algorithms.
* Prepare for coding assessments and technical interviews.

### 💻 Problem-Solving Practice

* Practice DSA problems categorized by topic.
* Work through problems of varying difficulty.
* Improve logical thinking and coding skills through consistent practice.
* Build a foundation for technical interview preparation.

### 📈 Learning Progress

* Track your problem-solving progress.
* Organize your practice across different DSA topics.
* Monitor your learning journey and identify areas for improvement.

### 🔐 User Authentication

* User registration and login functionality.
* Secure authentication using Spring Security and JWT.
* REST API integration between the frontend and backend.

### 🎯 Interview Preparation

* Practice commonly used DSA concepts and problem-solving patterns.
* Improve coding efficiency and algorithmic thinking.
* Build confidence for technical interviews and coding assessments.

## 🛠️ Technology Stack

### Frontend

* **React.js** – Building the user interface.
* **Vite** – Frontend development server and build tool.
* **CSS3** – Styling and responsive layouts.
* **Axios** – Connecting the frontend to backend APIs.

### Backend

* **Java** – Core programming language.
* **Spring Boot** – Developing backend services and REST APIs.
* **Spring Security** – Securing application endpoints.
* **JWT (JSON Web Token)** – Token-based authentication.
* **Maven** – Dependency management and project build.

### Database

* **MySQL** – Relational database for application data.

### Deployment

* **Vercel** – Frontend hosting.
* **Render** – Backend hosting.
* **Railway** – Database hosting, when configured.

## 🧭 How to Use

1. Open the CodeRivix application.
2. Register a new account or log in.
3. Explore the available DSA practice topics.
4. Choose problems based on your learning goals and difficulty level.
5. Practice regularly to strengthen your problem-solving skills.
6. Review your progress and continue preparing for technical interviews.
